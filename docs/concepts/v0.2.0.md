## Charm v0.2.0: The Universal Interface

### The Objective

Goal: Establish a Universal Interface Protocol for AI Agents.

In this phase, we are building the foundational kernel of Charm.

Our primary objective is to establish a standardized way to describe and interface with agents, ensuring that whether an agent is built with different frameworks or written as a pure Python script, it can be wrapped, loaded, and executed through a unified entry point without modifying its original source code.

### Key Deliverables
We are focusing on three core modules:

1. Unified Agent Contract (UAC)

See [here](https://github.com/CharmAIOS/Charm/blob/main/docs/contracts/uac/README.md) for details.

 > Note: You will notice that the UAC schema includes fields like `Capabilities` and `Tools`. We have intentionally reserved these interfaces in v0.2. While full-scale dynamic injection is planned for a future version, defining them now ensures forward compatibility and provides a conceptual preview. This means agents built with Charm today will be store-ready and able to accept external tools immediately when the full runtime launches

2. The Universal Wrapper SDK

Definition: A lightweight Python library that acts as the **Driver**.

Scope:

- Bootstrapping: Dynamically loads the agent based on the UAC configuration.

- I/O Normalization: Ensures that inputs and outputs are converted into standard JSON, regardless of the underlying framework's native format.

- Isolation: Catches internal framework errors and surfaces them as standard system signals.

3. CharmAgent Adapters

Definition: The translation layer for specific sources.

Purpose: Ensures that the Wrapper architecture is truly polymorphic and capable of handling different execution paradigms (e.g., task-based vs. graph-based).


### Scope & Boundaries
To ensure a focused release, we are setting clear boundaries for v0.2.0:

In Scope:

- Local Execution: Running agents on a developer's local machine via the SDK.
- Stateless Interactions: Single-turn or ephemeral multi-turn conversations.
- Public Interfaces: Standardizing how data enters and leaves the agent.

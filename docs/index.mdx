## What is Charm?

**Charm** is a unified application layer that turns your AI agents into real-world business applications in just a few commands.

### Why Charm?

- **Ecosystem Agnostic**: Use your favorite agent framework (CrewAI, LangChain, LangGraph) and run it with Charm.
- **No Infrastructure**: Run and test your agent locally in an isolated Docker environment with no API keys required.
- **No UI Code**: Render rich, server-driven user interfaces directly from your agent's output using our UI protocol.
- **Zero-Config**: Run and test your agent locally in an isolated Docker environment with no API keys required.
- **Open Source**: Charm is open source and community driven.

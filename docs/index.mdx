## Why Charm?

- **Ecosystem Agnostic**: Supports CrewAI, LangChain, LangGraph, OpenClaw, and more.
- **Zero-Ops Infrastructure**: Push your code. Charm instantly provisions and manages isolated cloud containers, handles dependencies and scales automatically.
- **Server-Driven UI**: Never write frontend code again. Agents return markdown or JSON, and Charm renders dynamic, native UIs directly on the user's device.
- **Built-in Monetization**: Configure subscriptions, one-time payments, or earn-as-you-go revenue sharing directly from your `charm.yaml` manifest.

## Start Here

<Steps>
  <Step title="Write Your Agent">
    Develop your core agent logic using your preferred framework. You don't need to learn a new way to write AI—just write pure Python or TypeScript.
  </Step>
  <Step title="Configure the Manifest">
    Add a `charm.yaml` file to your project root. Define your required API keys, UI schema, and execution environment (Standard or Full).
  </Step>
  <Step title="Test Locally">
    Use `charm run --docker` to simulate the exact production cloud environment on your local machine, ensuring 100% parity before deployment.
  </Step>
  <Step title="Publish & Monetize">
    Run `charm push`. Your agent is instantly bundled, deployed to the Charm Cloud Runner, and listed on the Charm Store for users to discover and install.
  </Step>
</Steps>

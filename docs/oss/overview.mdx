Charm is open source so agent builders can inspect, extend, and improve the core developer experience around packaging, running, publishing, and monetizing AI agents.

## What You Can Contribute

Contributions can include:

- SDK and CLI improvements.
- Agent templates.
- Runtime adapters.
- Documentation.
- Bug fixes.
- Test coverage.
- Platform integration ideas.
- Developer experience improvements.

## Start Here

- Read the [Contributing Guide](/oss/contributing).
- Set up your [Development Environment](/oss/dev-setup).
- Review the [Code of Conduct](/oss/code-of-conduct).
- Browse open issues on GitHub.

## Community Channels

- GitHub: code, issues, pull requests, release history.
- Discord: discussion, support, early feedback.
- Docs: public guides and contributor reference.

## Project Direction

The open-source roadmap focuses on:

- reliable SDK releases,
- clear templates,
- predictable runtime behavior,
- contributor-friendly docs,
- secure publishing and deployment workflows.

## Planned Flow

1. Merge approved changes.
2. Cut release candidate.
3. Validate staging.
4. Generate changelog draft.
5. Publish package artifacts.
6. Create GitHub Release.
7. Update docs.

## Required Checks

- Package build.
- Tests.
- Changelog draft.
- Docs build.
- Staging smoke tests.

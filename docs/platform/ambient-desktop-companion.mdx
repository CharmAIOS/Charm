Charm Desktop is the direction for local, ambient agent experiences that complement cloud-hosted agents.

## What It Is

The desktop companion is intended for agents that need:

- local file context,
- desktop notifications,
- hardware or OS proximity,
- persistent user workflows,
- handoff between local and cloud execution.

## Relationship to Charm Store

Charm Store is where users discover and launch agents. The desktop companion can extend those agents into local workflows when the use case requires local context.

## Local vs Cloud

Cloud execution is best for managed, isolated, scalable tasks. Local execution is useful when an agent needs user-device context or local permissions.

Charm runs agents inside managed container images. Choose the smallest image that supports your workload.

## Configure Runtime Mode

```yaml
runtime:
  mode: "standard"
```

Valid values:

- `standard`
- `full`
- `custom` (when paired with `custom_image`)

## Standard Runtime

Use `standard` for most Python agents.

Best for:

- text processing,
- API calls,
- lightweight data workflows,
- RAG-style agents,
- simple LangChain/LangGraph/custom agents.

It is optimized for lower cold-start time and smaller dependency footprint.

## Full Runtime

Use `full` when the agent needs browser or multimedia support.

Best for:

- Playwright, Selenium, Puppeteer,
- FFmpeg or audio/video workflows,
- OpenClaw agents,
- browser-rendered output.

## Custom Images

If neither `standard` nor `full` meet your needs (e.g. you need specialized system libraries or you are building your own adapter), you can provide a `custom_image` URL. 

```yaml
runtime:
  mode: "custom"
  custom_image: "ghcr.io/your-org/your-custom-runtime:latest"
```

## Choosing a Mode

Start with `standard`. Move to `full` only when a dependency requires it. If you need a fully custom environment, build a custom image based on our provided base images.

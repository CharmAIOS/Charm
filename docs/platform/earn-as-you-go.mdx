Earn As You Go is Charm's usage-based creator revenue model.

## Concept

Instead of earning only from an install or subscription, creators can earn when users run agents that create value.

## What May Affect Earnings

Revenue can depend on:

- user plan,
- agent pricing,
- execution cost,
- successful completion,
- payout policy,
- platform fees.

## Creator Dashboard

Creator dashboards should help authors understand:

- runs,
- revenue events,
- pending balance,
- available balance,
- payouts,
- refund or adjustment events.

## Getting Started

To prepare an agent for monetization:

1. Set pricing in `charm.yaml`.
2. Publish and test the listing.
3. Verify billing behavior in staging or with test accounts.
4. Monitor usage and revenue after launch.

## Notes

Keep user value clear. Usage-based revenue works best when users understand what each run produces.
